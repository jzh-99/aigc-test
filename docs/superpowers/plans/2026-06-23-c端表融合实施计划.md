# C端表融合 Implementation Plan

## 目标

将已确认的 C 端小程序表结构融合到本项目现有 B 端数据模型，支持：

- 个人账号登录默认拥有个人账号空间/个人团队/默认工作区。
- 同一用户同时拥有个人和团队账号时，登录响应提供账号类型选择数据。
- 业务配置数据按 `client_scopes` 投放到 C 端小程序、B 端企业端、H 端中屏。
- 业管平台后续全量推送的数据在本项目持久化保存。

## 端范围

- `mini_program`：C 端小程序。
- `enterprise`：B 端企业端。
- `screen`：H 端中屏。

`client_scopes` 使用 PostgreSQL `text[]`，避免逗号字符串解析歧义，并保留数组查询能力。

| `user_info` | 由现有 `users` 表替代。 |

## 实施任务

1. 新增 DB 迁移和 schema 类型。
2. 扩展个人团队类型与登录 profile。
3. 在登录、SSO、refresh 链路补齐个人账号空间。
4. 保留现有企业团队/工作区逻辑，企业团队 owner 冲突检查排除个人团队。
5. 运行 `pnpm --filter @aigc/db build` 和 `pnpm --filter @aigc/api build` 验证。
