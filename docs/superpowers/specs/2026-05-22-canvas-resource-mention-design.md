# 画布资源 @ 引用设计

## 目标

在画布图片生成节点和视频生成节点的参数面板中，为提示词输入增加 `@` 资源引用能力。用户可以从当前节点已连接的上游图片、视频、音频资源中选择一个资源，并针对该资源写局部约束；提交生成接口前自动转换成模型更容易理解的中文参考提示词。

## 交互

- 用户在提示词 textarea 中输入 `@` 时，弹出当前节点可用参考资源列表。
- 资源按现有连线顺序和媒体类型编号，展示为 `图片1`、`视频1`、`音频1`，并带来源节点名称。
- 选择资源后，在光标位置插入 `@图片1 `、`@视频1 `、`@音频1 `。
- 当前节点提示词限制为 500 字，面板显示 `当前字数/500`。超过限制时截断输入；提交前仍会校验。

## Prompt 转换

节点配置中继续保存用户原文，避免破坏已有编辑体验。提交接口前生成最终 prompt：

- 先保留原有上游文本节点内容。
- 再解析本节点 prompt 中包含 `@资源N` 的行或句子。
- 含 `@图片N` 的片段转换为 `图片参考：参考<图片N>中的...`
- 含 `@视频N` 的片段转换为 `视频参考：参考<视频N>中的...`
- 含 `@音频N` 的片段转换为 `音频参考：参考<音频N>中的...`
- 不含资源标记的文本作为整体提示词保留。

## 范围

- 前端实现，不改变后端 API 契约。
- 图片节点继续传 `params.image` 作为参考图 URL。
- 视频节点继续传 `reference_images`、`reference_videos`、`reference_audios` 或关键帧 `images`。
- 本次不做复杂富文本 token，先用 textarea 可读标记方案，降低对现有画布配置的影响。
