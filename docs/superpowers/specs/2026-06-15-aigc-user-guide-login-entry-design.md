# AIGC 用户使用手册登录页入口设计

## 目标

在登录页为首次使用平台的普通创作用户提供一个低调、可发现的使用手册入口，并新增一份图文并茂的完整用户使用手册。手册只覆盖创作相关功能，不包含用户、团队、后台管理、设置、充值等管理类功能。

## 用户范围

目标读者是已经获得平台账号、准备了解如何创作内容的普通用户。读者可能不了解平台导航结构，需要从“登录前先看一眼平台能做什么”进入手册，也需要在后续文档页中按功能查阅具体步骤。

## 页面入口设计

登录页保持现有左右分栏、品牌视频和登录表单结构不变。不新增大按钮、卡片或弹窗，只在现有底部协议文案附近增加一个文本链接：

```text
首次使用可查看《AIGC 用户使用手册》
```

链接样式与现有 `《用户协议》`、`《隐私政策》`保持一致，作为低调辅助入口存在。点击后跳转到独立文档页 `/docs/user-guide`。

## 手册页面设计

新增 `/docs/user-guide` 文档页，并在 docs 侧边栏“开始使用”分组中加入“用户使用手册”。文档使用现有 MDX 文档体系和 `docs-images` 图片资源，不新增新的文档框架。

手册内容结构：

1. 平台首页与功能入口
   - 说明首页三类主要入口：AI 生图、AI 视频、灵动画布。
   - 引导用户通过侧边栏进入创作生成、资产库、画布、Toby Studio 等模块。
2. AI 生图
   - 说明文生图、参考图上传、提示词、模型参数、数量、提交与查看结果。
   - 使用现有图片生成截图。
3. AI 视频
   - 说明快速视频生成、首尾帧、参考生视频、参数、提交与结果查看。
   - 使用现有视频生成截图。
4. 资产库与历史详情
   - 说明图片/视频资产筛选、日期筛选、预览、下载、复用、删除与回收站。
   - 强调历史详情与资产库都可回看结果。
5. 灵动画布
   - 说明制作视频、生成图片、自由创作三个入口。
   - 说明画布中通过节点串联素材、提示词、图片、视频等创作流程。
6. 视频工坊
   - 说明从故事描述到剧本、分镜、角色、视频生成的流程。
   - 说明项目列表、新建项目、回收站与继续编辑。
7. Toby Studio 专项创作
   - 说明音乐、绘本、短剧等专项模块是独立内容工作室入口。
   - 手册只做入口级说明，避免虚构未研读到的细节。
8. 常见操作建议
   - 说明生成任务提交后可切换页面，结果会保存在历史或资产中。
   - 说明复用参数适合在满意结果基础上继续微调。
   - 说明遇到 A 豆不足或无工作区提示时，应联系团队负责人。

## 数据与交互影响

本设计只新增静态文档页和登录页链接，不改变登录表单提交、鉴权、SSO、账号停用提示、跳转逻辑或任何 API 数据流。登录页链接不需要额外状态，不影响防重复提交逻辑。

## 错误处理

手册页是静态 MDX 内容，不引入新的数据请求。若图片资源缺失，浏览器会显示图片加载失败状态；实施时应只引用已存在的图片路径。

## 验证方式

实施后进行静态检查：

1. 确认登录页存在低调文本链接，链接地址为 `/docs/user-guide`。
2. 确认 docs 侧边栏出现“用户使用手册”入口。
3. 确认新增 MDX 中引用的图片文件均存在。
4. 不启动本地 dev server，不刷新 `localhost:6006`，不执行前端构建预览。

## 非目标

- 不新增注册、找回密码、团队管理、管理员后台、A 豆充值或设置页说明。
- 不修改登录认证流程。
- 不新增动态引导、弹窗、产品导览或埋点。
- 不补拍或生成新的截图。
