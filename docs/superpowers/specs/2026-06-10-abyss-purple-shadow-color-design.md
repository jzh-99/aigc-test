## 1. 背景与目标

当前全站主色调 hue ≈ 222（深海军蓝），背景色 `#080D1A`、卡片色 `#0D1525` 蓝色感明显。用户期望将整体配色「偏黑」而非偏蓝，但保留与现有 primary 紫 `#C89CEC` 的统一感。

**核心决策：**
- 背景方向：极深紫黑（hue ~275），几乎纯黑但带一丝紫
- 强调色渐变：蓝→紫→黑（蓝紫黑渐变）
- 交互状态：保留蓝色系，形成「紫黑底 + 蓝色交互」的层次对比
- Primary / Secondary 色不变

## 9. 设计原则总结

1. **底色紫黑化**：所有 hue 222 蓝色背景 → hue 275 紫黑，蓝感消失
2. **蓝色退居交互层**：按钮 hover、链接、节点状态保留蓝色，形成「紫黑底 + 蓝色交互」的层次
3. **紫色与 primary 统一**：边框、阴影、光晕的蓝色成分替换为与 `#C89CEC` 同源的紫色
4. **强调色渐变改为蓝→紫→黑**：从橙紫蓝三色改为蓝紫黑，视觉更统一
